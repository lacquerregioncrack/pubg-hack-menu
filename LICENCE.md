## 🧩 About

**PUBG Hack Menu** is a curated list of PUBG open-source tools:

- **Overlays** — on-screen helpers, layout notes, radar viewer, loot tracker
- **Quality-of-Life Helpers** — config manager, map notes, HUD layout presets
- **Research Notes** — match layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Map Radar — visualize nearby points on a study map
- Loot Tracker — organize item spawn notes
- Replay Notes — record and review match runs
- View Scale — adjust overlay scale for study (0.1x to 5x)

### Wallhack
- HUD Catalog — browse HUD presets, colors, and layouts
- Custom Config Notes — organize per-match settings
- Marker Visibility — improved marker outlines for study

### Aimbot
- Training Notes — segment study on any layout
- Movement Control — manually switch movement modes in practice
- Input Buffer Notes — chain complex maneuvers in the training map
